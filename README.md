# May Blast

Juego de bloques para navegador, hecho con HTML, CSS y JavaScript sin dependencias de instalación.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub y sube `index.html` y este `README.md` a la raíz.
2. En el repositorio, abre **Settings > Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/(root)`, y guarda los cambios.
5. Abre la URL que GitHub Pages muestre en esa sección.

El juego guarda el récord en el almacenamiento local del navegador.
